# NannyMEサイト プロトタイプ

WordPressを使わず、ReactとViteで構築したNannyMEサイトのフロントエンドプロトタイプです。公開されているサイトを参考にしていますが、NannyME公式のサイトやサービスではありません。

## ローカルで起動

```sh
npm install
npm run dev
```

## ビルド

```sh
npm run build
```

## ページ

- トップページ
- ABOUT
- NannyMEについて
- NEWS TOPICS
- ご利用料金
- 利用の流れ
- FAQ
- お問い合わせ
- English
- Nanny向け案内

## 使用技術

- React
- Vite
- CSS

## 素材について
